# Support

For installation or app behavior help, use the
[HEA-World contact page](https://hea-world.com/hea_pages/hea_contact.html).
For Reachy Mini hardware or daemon issues, use the
[official Reachy Mini documentation](https://huggingface.co/docs/reachy_mini/index).

Before contacting support, use **Export safe diagnostics** in the local app.
Open the JSON file and review it before sharing. It contains app/runtime state,
the selected public HEA identity, error codes, and recent speech/motion outcomes.
It deliberately excludes questions, answers, sentence text, audio,
visitor/session identifiers, and raw exceptions.

Do not send credentials, private HEA identifiers, conversation text, audio, or
other personal data. If Reachy is moving unexpectedly, use **Stop & neutral** or
stop the app in Reachy Mini Control before collecting diagnostics.
